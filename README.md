# Crypto Currency Market Analysis

## Project Overview
This Power BI project analyzes cryptocurrency market trends and performance using interactive dashboards and visualizations.

The dashboard provides insights into:
- Market capitalization
- Trading volume
- Price trends
- Top performing cryptocurrencies
- Market performance analysis

## Tools & Technologies Used
- Power BI
- Data Cleaning
- DAX Measures
- Data Visualization
- Cryptocurrency Dataset

## Dashboard Features
- Interactive Filters & Slicers
- KPI Cards
- Trend Analysis
- Market Comparison
- Dynamic Visualizations

## Files Included
- Cryptocurrency Market Analysis Project.pbix
- Crypto_dataset.zip

## Project Objective
The objective of this project is to analyze cryptocurrency market behavior and create interactive dashboards for better business insights and decision-making.
